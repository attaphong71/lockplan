# LockPlan — แอปวางแผนงาน + หน้าจอล็อก (ฟรี ไม่มีค่ารายปี)

## ติดตั้ง (ทำครั้งเดียว ~5 นาที, ใช้ Windows ได้)
1. สมัคร/ล็อกอิน https://github.com → New repository → ชื่อ `lockplan` → Public → Create
2. กด **uploading an existing file** → ลากไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้นไป → Commit
3. Settings → Pages → Source: **Deploy from a branch** → Branch `main` / `(root)` → Save
4. รอ 1–2 นาที ได้ลิงก์ `https://<ชื่อคุณ>.github.io/lockplan/`
5. บน iPhone เปิดลิงก์ด้วย **Safari** → ปุ่มแชร์ → **เพิ่มไปยังหน้าจอโฮม**

## หน้าจอล็อก
แท็บ "ล็อก" → ทำตามขั้นตอนคำสั่งลัด (ทำครั้งเดียว) → ต่อไปกด "อัปเดตหน้าจอล็อก" แล้วเลือกคำสั่งลัด

## ข้อมูล
เก็บในเครื่องเท่านั้น สำรองได้ที่ ตั้งค่า → สำรองข้อมูล → บันทึกลง iCloud Drive
อัปเดตแอป: อัปโหลดไฟล์ใหม่ทับใน GitHub แล้วแก้ `V` ใน sw.js (เช่น lockplan-v2)
